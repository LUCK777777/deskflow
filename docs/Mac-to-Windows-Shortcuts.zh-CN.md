# Mac 键盘控制 Windows 快捷键大全

这份表适用于 Deskflow 测试版。用插在 Windows 上的共享鼠标进入 Windows 屏幕后，再按 Mac 内建键盘。共享鼠标移回 Mac 后，键盘按 macOS 的常规键位工作。动 Mac 触控板可以唤回本机光标，打字仍跟随共享鼠标。

`⌘` 是 Command，`⌃` 是 Control，`⌥` 是 Option，`⇧` 是 Shift。右栏的 `Win` 表示 Windows 徽标键。

## 剪贴板与文字编辑

| Mac 键盘 | Windows 收到 | 用途 |
| --- | --- | --- |
| `⌘V` | `Win+V` | 打开 Windows 本机剪贴板历史 |
| `⌃V` | `Ctrl+V` | 粘贴 Windows 剪贴板的当前内容 |
| `⌘⇧V` | `Ctrl+Shift+V` | 在支持的应用中粘贴为纯文本 |
| `⌘C` | `Ctrl+C` | 复制 |
| `⌘X` | `Ctrl+X` | 剪切 |
| `⌘A` | `Ctrl+A` | 全选 |
| `⌘Z` | `Ctrl+Z` | 撤销 |
| `⌘⇧Z` | `Ctrl+Y` | 在使用 Ctrl+Y 的应用中重做 |
| `⌘F` | `Ctrl+F` | 查找 |
| `⌘G` | `Ctrl+G` | 查找下一处或转到指定位置，具体取决于应用 |

按 `⌘V` 后可用 ↑／↓ 选历史项目，按回车粘贴，按 Esc 关闭。首次使用时，Windows 可能提示开启剪贴板历史。这里使用 Windows 本机的历史记录，Deskflow 的剪贴板同步是独立设置。[微软剪贴板说明](https://support.microsoft.com/en-us/windows/apps/using-the-clipboard)

## 文件、窗口与浏览器

| Mac 键盘 | Windows 收到 | 用途 |
| --- | --- | --- |
| `⌘S` | `Ctrl+S` | 保存 |
| `⌘⇧S` | `Ctrl+Shift+S` | 在支持的应用中另存为 |
| `⌘O` | `Ctrl+O` | 打开文件 |
| `⌘N` | `Ctrl+N` | 新建窗口或文档 |
| `⌘P` | `Ctrl+P` | 打印 |
| `⌘W` | `Ctrl+W` | 关闭当前标签、文档或窗口，具体取决于应用 |
| `⌘⇧N` | `Ctrl+Shift+N` | Edge／Chrome 开隐私窗口，文件资源管理器新建文件夹 |
| `⌘T` | `Ctrl+T` | 新建浏览器标签 |
| `⌘⇧T` | `Ctrl+Shift+T` | 恢复刚关闭的浏览器标签 |
| `⌘L` | `Ctrl+L` | 跳到地址栏 |
| `⌘R` | `Ctrl+R` | 刷新 |
| `⌘=` | `Ctrl+=` | 放大页面 |
| `⌘-` | `Ctrl+-` | 缩小页面 |
| `⌘0` | `Ctrl+0` | 恢复页面默认缩放 |

查找、重做、纯文本粘贴和另存为的行为由当前 Windows 应用决定。[微软 Mac 与 Windows 对照](https://learn.microsoft.com/en-us/windows/dev-environment/mac-to-windows) · [Edge 快捷键](https://support.microsoft.com/en-us/edge/keyboard-shortcuts-in-microsoft-edge)

## Windows 系统操作

| Mac 键盘 | Windows 收到 | 用途 |
| --- | --- | --- |
| `⌥Tab` | `Alt+Tab` | 切换一次 Windows 窗口 |
| `⌥⇧Tab` | `Alt+Shift+Tab` | 反向切换一次 Windows 窗口 |
| `⌘⌥Tab` | `Win+Tab` | 打开任务视图，看所有 Windows 窗口 |
| `⌘⌥E` | `Win+E` | 打开文件资源管理器 |
| `⌘⌥D` | `Win+D` | 显示桌面，再按还原窗口 |
| `⌘⌥S` | `Win+S` | 打开 Windows 搜索 |
| `⌘⌥I` | `Win+I` | 打开 Windows 设置 |
| `⌘⌥R` | `Win+R` | 打开「运行」窗口 |
| `⌘⌥W` | `Alt+F4` | 关闭 Windows 当前窗口 |
| `⌘⌥⇧S` | `Win+Shift+S` | 打开 Windows 区域截图 |

用 `⌘Tab` 切换 Mac 本机应用，用 `⌥Tab` 切换 Windows 窗口。想从多个 Windows 窗口中挑一个，用 `⌘⌥Tab` 打开任务视图。[Apple 快捷键](https://support.apple.com/guide/mac-help/keyboard-shortcuts-mchlgtd_kbd01/mac) · [微软 Windows 快捷键](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows)

## 按原键转发的导航键

| Mac 键盘 | Windows 收到 |
| --- | --- |
| `Tab`、`⇧Tab`、`Esc` | `Tab`、`Shift+Tab`、`Esc` |
| `←`、`→`、`↑`、`↓` | 对应的 Windows 方向键，可长按 |
| `Home`、`End` | `Home`、`End` |
| `Page Up`、`Page Down` | `Page Up`、`Page Down` |
| 英数字、常见标点、退格和回车 | 延续测试版的文本按键转发 |

Mac 字母快捷键使用内建键盘的 ANSI 物理键位。带修饰键的映射都是单次按键动作。Windows 应用自己的快捷键定义、中文输入法组字和豆包语音各由对应应用处理。参考 [Microsoft Windows App 的 Mac 键位映射](https://learn.microsoft.com/en-us/windows-app/input-keyboard-mouse-touch-pen?tabs=macos) 和 [UU 远程按键映射](https://uuyc.163.com/features/keyboard/)。
